# reach-airgap-demo

**PUBLIC.** The target application that crosses the air gap — a captured
multi-service treasury portal (`fintech-treasury-portal`, provenance:
`reach-vibe-throwdown/apps/`), plus committed scan ground truth and the
published demo transcript pages.

Design: `reach-core/docs/design/AIRGAP-DEMO.md` (v3). The private side —
`reach-airgap-core` — holds the compose topology, phase scripts and every
credential. This repo holds **no keys and no workflows**: it is the thing
that crosses the gap (§8).

## Layout

- `app/` — polyglot services: `portal/` (Node/TS, lockfile),
  `payments-api/` (Go, go.mod), `risk-api/` (Java), `docs-worker/` (Python)
- `ground-truth.json` — expected findings; the enclave scan asserts against
  it (design §8). **Generated by a lowside scan of this tree, never
  hand-written** — a hand-written truth proves nothing about the scanner.
- `docs/` — public demo pages, populated in stage 3+ (§14)

## Why this app

The design requires a real multi-level dependency closure, a lockfile, and
findings worth reporting. This specimen gives npm + Go + Python manifests
across four services — the registry lane (§5b) actually has work to do.
`app/fixture.json` declares no per-finding ground truth, which is why the
first lowside scan must produce it before any green run is believed.
